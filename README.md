# Netflix Data Analysis Project

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset. The objective is to understand content trends, genre distribution, ratings, country-wise contributions, and Netflix's content growth strategy.

---

## Dataset Information

* Dataset: Netflix Movies and TV Shows
* Total Records: 8,797
* Total Features: 12

### Features

* show_id
* type
* title
* director
* cast
* country
* date_added
* release_year
* rating
* duration
* listed_in
* description

---

## Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Data Cleaning Performed

* Checked dataset structure and data types
* Identified missing values
* Replaced missing values in director, cast, and country columns
* Removed records with missing date_added values
* Corrected missing rating and duration values
* Converted date_added into datetime format
* Verified duplicate records

## Key Insights

* Movies account for nearly 70% of Netflix content.
* The United States contributes the highest number of titles.
* India is the second-largest content contributor.
* International Movies are the most common genre.
* TV-MA is the most frequent content rating.
* Netflix content growth accelerated significantly after 2015.
* Most movies have durations between 90 and 120 minutes.
* July and December have the highest content additions.
* Netflix strongly focuses on international content.
